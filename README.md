# 321theology2

## v1.0-co1（2026-11-02）新增「一起共讀」
- 每頁頂端列的 📡：帶領者「開共讀房間」，得到 6 位數共讀碼、QR 與邀請連結（`?join=碼`）；加入者輸入碼或點連結，畫面跟著帶領者換到同一個分頁、同一課、同一個版本，並同步捲動位置。
- 帶領者朗讀到哪一句、點了哪一句，加入者那一句會亮起外框並捲到畫面中央。每個人的語言與字級各自保留（只傳課號與句序，不傳文字）。
- 設定、我的、金句記憶、美圖工作室、小智屬於個人頁面，不同步；加入者可自己瀏覽，8 秒內不會被拉回，點上方標籤可回到帶領者。
- 「複製投影連結」：在連接投影機的電腦／平板打開，會變成大字、隱藏介面、自動跟著帶領者的投影螢幕。
- 新增 `coread.js`（三冊神學共用同一份）與 `peerjs.min.js`（Cloudflare 中繼站連線層）；`sw.js` 版本加 `-co1` 並預先快取這兩個檔。
- 兩邊（帶領者與加入者）都要更新到這一版才能一起共讀。

## v1.3（2026-10-20）新增「美圖工作室」（與創世記至彼得後書同一套）
- **哪裡進去**：畫面左下角的 🖼 鈕（先在畫面上選取一段話再按，會自動帶進來，也可自己貼上）；小智回答下方的「🖼 做成美圖」。「我的作品」在美圖工作室裡的「我的作品」按鈕。
- **做什麼**：9 種版型、5 種尺寸、6 種外框；相片可用內建圖庫、免費圖庫或自己的相簿；**AI 生成美圖**（寫好提示詞，可在 App 內直接生成，或複製到 Gemini／ChatGPT／豆包／Pollinations）；**AI 生成配樂**（Suno／MusicFX／Stable Audio 提示詞）；卡片字體（明體／黑體／楷體／圓體）與文字顏色；詩歌配樂、錄音、卡片影片、自拍影片。
- **自拍相機打不開**時會說清楚原因並給兩條退路；離開去第三方工具再回來，自動接回原位。
- 這一版是獨立模組（自己的作品與設定存在本機，不動本 App 原有資料）。沒有 AI 影片（已決定不做）。
- 上傳：index.html（有的有 sc.html／en.html）、sw.js、README.md 一起覆蓋。
